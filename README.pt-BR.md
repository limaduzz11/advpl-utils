# Utilitários ADVPL

<br />

[English](README.md) &nbsp;|&nbsp; **Português (Brasil)**

<br />

Coleção de funções utilitárias reutilizáveis em ADVPL para TOTVS Protheus — manipulação de strings, tratamento de datas, operações de arquivo, e-mail e rotinas auxiliares.

> **Aviso Legal**: Funções utilitárias genéricas. Sem regras de negócio proprietárias ou código corporativo de clientes.

## Categorias

- **Manipulação de Strings** — Formatação, sanitização e validação
- **Tratamento de Datas** — Dias úteis, períodos e aging
- **Operações de Arquivos** — Manipulação de CSV, TXT e operações FTP
- **Utilitários de E-mail** — Envio via serviços nativos de mensageria do Protheus
- **Rotinas Auxiliares** — Manipulação de arrays, controle de alias e proteção de área (GetArea / RestArea)

## Tecnologias

`ADVPL` `TOTVS Protheus`
